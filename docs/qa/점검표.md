# 실제 터미널 점검표

자동 테스트는 한글 입력기(IME), 초점이 실제로 옮겨 가는지, 클립보드, 터미널 폭을 보지 못합니다.
새 판을 내기 전에 아래 장면을 사람이 직접 눌러 봅니다. 장면마다 **누를 것 → 보여야 할 글자**를 적었습니다.
보여야 할 글자가 다르면 `/learn 진단`을 복사해 이슈에 붙입니다.

환경은 네 가지입니다.

- **WT**: Windows Terminal + Microsoft 한글 입력기(한/영 키로 바꿈). 회사 사용자 대부분이 이 환경입니다.
- **VS Code**: VS Code 통합 터미널, 또는 Claude Code for VS Code 확장.
- **macOS**: 터미널 앱이나 iTerm2.
- **tmux**: 위 어느 터미널 안의 tmux.

준비: 빈 폴더에서 `claude`를 켜고, 전체 화면이 필요한 장면은 `/tui fullscreen`을 먼저 칩니다. 터미널 폭은 150칸 이상으로 둡니다(패널이 저절로 열리려면 144칸 이상이어야 합니다. 좁은 화면을 보는 줄만 예외).
글자 키는 패널에 키가 있을 때(`ctrl+x tab` 뒤) 누릅니다. 버튼은 패널에 `키: 이름`(예: `a: 정답 보기`)으로 보입니다.
장면 13부터는 1.7.0에서 바뀐 퀴즈(되묻기 · 한 번 더 · `모르겠어요` · 첫 답 전에 `a` 없음)와 직접 해 보기(`t`), 그 밖의 1.7.0 장면입니다. 장면 1~12도 1.7.0 문구로 고쳤으니 모두 다시 봅니다.

## 1. 버전 확인 (모든 환경)

| 누를 것 | 보여야 할 글자 |
| --- | --- |
| 대화 입력칸에 `/learn ` (공백까지) | 입력 힌트 `[복습\|퀴즈\|정리\|질문\|기록\|보고서\|공유\|진단\|도움말]` |
| `/learn 도움말` | 첫 줄이 `learn-notes 1.7.0 명령` (설치한 판의 번호). 모두 14줄(대화로 묻기 줄이 있으면 15줄) |
| WT를 100칸으로 줄이고 `/learn 도움말` | 맨 끝 `- 가끔: …` 줄과 ``- 퀴즈(`4`): …`` 줄이 단어 사이에서 줄바꿈되어 읽을 수 있음 |
| `/learn 진단` | `- 버전: learn-notes 1.7.0 · Claude Code 2.1.…` 줄, 그 아래 `- 다른 창: 없음` (지난 하루 안에 다른 claude 세션을 켰다면 지금 열려 있지 않아도 그 판과 `(n분 전)`·`(n시간 전)`이 최근 3개까지 보임) |

## 2. 첫 노트와 알림 (WT · macOS)

| 누를 것 | 보여야 할 글자 |
| --- | --- |
| 전체 화면에서 "hello.js에 인사하는 함수를 만들어 줘" | 턴이 끝나면 오른쪽 패널에 `노트 1/1 · … · 파일 1개` |
| 전체 화면이 아닌 화면(`/tui` 끔)에서 같은 요청 | 대화창에 흐린 줄 `학습 노트 · (한 줄 요약) · /learn으로 보기` |
| 터미널을 100칸으로 줄이고 `/learn` | 프롬프트 위에 패널이 열리거나, `이 화면에는 패널을 띄울 수 없어 마지막 노트를 여기에 적습니다` |
| 이어서 `/learn 진단` | `- 화면:` 줄에 `터미널 100칸(전체 화면 아님)` |

## 3. 숫자 키는 한/영 상관없이 (WT)

준비: 노트가 하나 있고, 한/영이 **한글** 상태입니다.

| 누를 것 | 보여야 할 글자 |
| --- | --- |
| `/learn` | 보기 줄 아래 `ctrl+x tab: 패널 고르기 · 숫자 키는 한/영 상관없이, 글자 키는 영문 상태에서` |
| `ctrl+x tab` | 그 줄이 `Esc: 대화로 돌아가기 · 글자 키는 영문 상태에서`로 바뀜 |
| 한글 상태 그대로 `2` | `2: 전/후`가 굵게 밑줄, 바뀐 줄에 `− 전` · `+ 후` |
| `3` | `배운 개념 n개` 제목 |

## 4. 글자 키는 영문 상태에서, Esc로 돌아가기 (WT)

| 누를 것 | 보여야 할 글자 |
| --- | --- |
| 패널에 키가 있고 한글 상태에서 `p` | 아무 일도 없음 (`ㅔ`가 들어가 단축키가 아님) |
| 한/영 키, 그다음 `p` | 이전 노트로 가거나, 첫 노트면 그대로 |
| `Esc` | 보기 줄 아래가 `ctrl+x tab: 패널 고르기 · …`로 돌아감 |
| 대화 입력칸에 `안녕` | 글자가 입력칸에 들어감 (패널 키로 먹지 않음) |

## 5. 한글로 답을 적고 Enter (WT)

준비: 복습할 개념이 있습니다(노트가 두세 개 쌓인 다음 날이 쉽습니다).

| 누를 것 | 보여야 할 글자 |
| --- | --- |
| `/learn 복습` | 패널이 퀴즈 보기로 열리고 커서가 `내 답` 칸에 있음 |
| 한글 상태로 `바깥 변수`를 치고 조합이 끝나기 전에 바로 Enter | `채점하는 중입니다…`, 채점 뒤 `내 답: 바깥 변수` (마지막 글자 `수`가 빠지지 않음) |
| 채점이 끝난 뒤 | 맞힌 답이면 커서가 다음 문제의 `내 답` 칸으로 옮겨 감. 거의·틀림이면 같은 문제에 `되묻기:` 줄과 빈 `내 답 (한 번 더)` 칸이 생기고 커서가 그 칸에 있음(한/영 그대로 적음). 한 번 더 채점 뒤 다음 문제 칸으로. 마지막 문제 뒤에는 `s: 새 문제 받기` |
| 빈 칸에서 Enter | 빨간 글씨 `모르겠으면 '모르겠어요'라고 적고 Enter · 막히면 h로 힌트` (힌트가 없거나 이미 봤으면 `· 막히면 h로 힌트` 없음) |

## 6. 답 칸에서 Tab으로 버튼에 (WT · macOS)

| 누를 것 | 보여야 할 글자 |
| --- | --- |
| `내 답` 칸에 커서가 있을 때 | 칸 아래 흐린 줄 `답 칸에서 Enter: 채점 · 모르면 '모르겠어요' · Tab: 버튼으로 (…)` (괄호 안은 힌트가 있는 문제면 `h 힌트 · 1~4 보기`, 위 문제에 `n`이 있으면 `n 배운 노트`도) |
| `Tab`, 영문 상태로 `h` | 노란 `힌트` 제목과 힌트 글 |
| `Tab`을 몇 번 눌러 `1`~`4` | 보기가 바뀜 (답 칸에 숫자가 들어가지 않음) |
| `4`로 돌아와 `Esc` | 칸 아래 줄이 `모르면 '모르겠어요'라고 적고 Enter`로 바뀜 (Tab 줄은 없음). 보기 줄 아래는 `ctrl+x tab: 답 칸으로 · 보기를 바꾸려면 그 뒤 Tab · 글자 키는 영문 상태에서` |

## 7. `/learn 진단` 복사와 붙여 넣기 (WT · macOS)

| 누를 것 | 보여야 할 글자 |
| --- | --- |
| `/learn 진단` | 첫 두 줄 `진단 내용을 클립보드에 복사했습니다 · 팀 채널이나 담당자에게 그대로 붙여 주세요`, `코드 · 요청 · 파일 이름 · 경로 · 개념 이름은 들어 있지 않습니다` |
| 메모장이나 Slack 입력칸에 붙여 넣기 | 첫 줄 `learn-notes 진단 · 날짜 시각`, 대화창에 적힌 진단과 같은 글 |
| 붙인 글을 훑어보기 | 내 요청 문장, `C:\` · `/Users/` 같은 경로, 파일 이름, 개념 이름이 없음 |
| WT에서 붙인 글의 `- 화면:` 줄 | 끝에 `Windows Terminal` |
| 퀴즈를 몇 문제 푼 뒤 `/learn 진단` | 초점 거절이 있었으면 맨 끝에 따로 `- 패널 초점(최근 7일): 초점 거절 ×n · 마지막 MM-DD HH:MM`. `- 오늘:` 줄의 실패 수에는 들지 않음 |

## 8. tmux 안에서 (tmux)

| 누를 것 | 보여야 할 글자 |
| --- | --- |
| tmux 안에서 `/learn 진단` | `- 화면:` 줄에 `tmux` |

## 9. VS Code에서 (VS Code)

| 누를 것 | 보여야 할 글자 |
| --- | --- |
| 통합 터미널의 `claude`에서 `/learn 진단` | `- 화면:` 줄 끝에 `vscode` |
| 확장(패널)에서 `/learn` | 학습 노트 패널이 열리고 노트가 보임 |

## 10. 쓸 수 없는 폴더: 원인 토스트와 다음 세션의 점검 줄 (WT · macOS)

준비: WT는 Windows 보안 → 랜섬웨어 방지 → **제어된 폴더 액세스**를 켜고 `/config`의 `saveDir`를 `문서` 아래 폴더로 둡니다. macOS는 `mkdir ~/ro && chmod 555 ~/ro` 뒤 `saveDir`를 `~/ro/notes`로 둡니다.

| 누를 것 | 보여야 할 글자 |
| --- | --- |
| 파일을 고치는 요청 | 토스트 `학습 노트를 파일에 쓰지 못했습니다: 폴더에 쓸 권한이 없습니다(Windows의 '제어된 폴더 액세스'나 보안 프로그램이 막았을 수 있습니다) · 다음 노트 때 다시 씁니다 · /learn 진단` |
| 한 번 더 요청 | 같은 토스트가 다시 뜨지 않음 (원인마다 세션에 한 번) |
| `/learn 진단` | `일지 저장 · 쓸 권한 없음(EACCES)` 또는 `(EPERM)`, `- 일지: 아직 못 쓴 노트 2개`. 노트 하나가 두 번 세지지 않음(노트 2개면 `×2`) |
| `claude`를 껐다 다시 켜기 | 대화창에 흐린 줄 `learn-notes 점검: 일지에 아직 못 쓴 노트 2개 (폴더에 쓸 권한 없음) · /learn 진단` (그날 한 번만) |
| `saveDir`를 비우고 요청 하나 더 | 일지 파일에 못 쓴 노트까지 세 노트가 들어감, `/learn 진단`에 `· 다시 써서 됨` (앞 세션의 기록에도) |
| 다음 날 `claude` 시작 | 점검 줄이 뜨지 않음 |

## 13. 첫 오답의 되묻기와 한 번 더 (WT)

준비: 복습할 개념이 있고, 패널은 전체 화면 오른쪽에 있으며, 한/영이 **한글** 상태입니다. 모델이 되묻기 없이 바로 채점하면(정답이 바로 펼쳐지면) 다음 문제로 다시 해 봅니다.

| 누를 것 | 보여야 할 글자 |
| --- | --- |
| `/learn 복습` | 커서가 `내 답` 칸에 있음. 칸 아래 버튼 줄에 `i: 답 적기`와(힌트가 있는 문제면) `h: 힌트`만 있고 **`a: 정답 보기`는 없음** |
| `Tab`으로 버튼에 가서 영문 상태로 `a` | 아무 일도 없음 (첫 답 전에는 `a`가 없음) |
| `i`로 칸에 돌아와, 한글 상태로 일부러 틀린 답을 적고 Enter | `채점하는 중입니다…` 뒤 **정답은 보이지 않고** 노란 `△ 아직입니다 · 방향은 맞습니다` 또는 빨간 `✗ 아직입니다 · 한 번 더 떠올려 보세요`, `내 답: (적은 답)`, 피드백, `되묻기: …` |
| 그대로(한/영을 바꾸지 않고) 한글을 침 | 커서가 빈 `내 답 (한 번 더)` 칸에 있어 글자가 그 칸에 들어감. 첫 답이 미리 채워져 있지 않음 |
| 칸 아래 흐린 줄 | `Enter: 다시 채점 · Tab: 버튼으로 (a 정답 · f 맞았는데요)` |
| `Tab`을 몇 번 | 초점이 버튼을 오가며 `i: 답 적기` · `a: 정답 보기` · `f: 맞았는데요`에도 감 (칸에 글자가 들어가지 않음) |
| 영문 상태로 `i`, 칸에 맞는 답을 적고 Enter | 위에 `✓ 맞힘 n. (개념) · 되짚어 맞힘 · 방금 채점`, 피드백과 `정답`. 커서가 다음 문제의 `내 답` 칸으로 (마지막 문제면 `s: 새 문제 받기`) |
| 다음 문제에서 첫 답을 틀리고, 한 번 더도 틀림 | 위에 `✗ 틀림 n. (개념) · 방금 채점`(두 번 다 거의였으면 `△ 거의 맞음`), 피드백과 `정답`이 이제 펼쳐짐. `o: 맞혔어요` · `x: 틀렸어요`는 없음 |
| 그다음 문제에서 첫 답을 틀린 뒤 `Tab` → 영문 상태로 `a` | 정답이 펼쳐지고 곧바로 `✗ 틀림`(첫 답이 거의였으면 `△ 거의 맞음`)으로 매겨짐. `o` · `x` 버튼이 나오지 않음. 커서가 다음 문제 칸으로 |
| 새 퀴즈(`s` 두 번)에서 첫 답을 틀린 뒤 `Tab` → `f` | `✓ 맞힘`으로 매겨지고 피드백 끝에 `(내가 맞힘으로 바꿈)` |
| 퀴즈를 다 푼 뒤 끝 줄 | 되짚어 맞힘이 있었으면 `힌트·되묻기·정답을 보고 맞힌 개념은 같은 간격 뒤 다시 나옵니다` |

## 14. `모르겠어요`와 빈 Enter (WT)

준비: 장면 13처럼 퀴즈 보기에 새 문제가 있고 한글 상태입니다. 힌트가 있는 문제(`h: 힌트`가 보이는 문제)를 고릅니다.

| 누를 것 | 보여야 할 글자 |
| --- | --- |
| 빈 칸에서 Enter | 빨간 `모르겠으면 '모르겠어요'라고 적고 Enter · 막히면 h로 힌트` |
| `모르겠어요`를 적고 Enter | 곧바로(모델 호출 없이) 노란 `힌트를 보고 한 번 더 떠올려 보세요`와 `힌트: …`, 빈 `내 답 (한 번 더)` 칸. `내 답:` 줄은 없음 |
| 칸 아래 흐린 줄 | `Enter: 다시 채점 · Tab: 버튼으로 (a 정답)` (`f`는 없음) |
| `모르겠어요`를 한 번 더 적고 Enter | 위에 `✗ 틀림 n. (개념) · 힌트 봄 · 방금 채점`, `아쉽지만 틀렸습니다. 정답을 읽어 보고, 다음에 이 개념이 나오면 다시 떠올려 보세요.`, 흐린 `떠오르지 않았습니다 · 다음 퀴즈에서 다시 풉니다`, `정답` |
| 힌트가 없는 문제에서 `모르겠어요` | 바로 `✗ 틀림`과 정답 (한 번 더 칸 없음) |
| 이 장면 앞뒤로 `/learn 기록` 맨 아래 | 모델 호출 수가 `모르겠어요`만큼 늘지 않음 |
| 대화 입력칸에 `/learn 퀴즈 모르겠어요` (풀던 퀴즈의 1번이 힌트가 있는 문제일 때) | 첫 줄이 `1번 답으로 받았습니다` (`채점했습니다`가 아님), 그 아래 `1번 힌트를 보고 한 번 더 떠올려 보세요`, `힌트: …`, `한 번 더: /learn 퀴즈 1 새 답 · 정답: /learn 퀴즈 정답 1` |

## 15. 대화창과 휴대폰에서 되묻기 (WT · Remote Control)

| 누를 것 | 보여야 할 글자 |
| --- | --- |
| 대화 입력칸에 `/learn 퀴즈 새로`, 그다음 `/learn 퀴즈 1 (틀린 답)` | 세 줄: `1번 △ 아직입니다 · …`(또는 `✗ 아직입니다 · …`), `되묻기: …`, `한 번 더: /learn 퀴즈 1 새 답 · 정답: /learn 퀴즈 정답 1` |
| `/learn 퀴즈 1 새 답` (자리표시를 그대로) | 채점하지 않고 `'새 답' 자리에 떠올린 답을 적어 보내 주세요: /learn 퀴즈 1 (떠올린 답)` |
| `/learn 퀴즈` | 1번 문제 아래 `내 답: …`과 `되묻기: …`가 다시 보이고 끝에 `한 번 더: /learn 퀴즈 1 새 답 · …` |
| 휴대폰 앱에서 퀴즈 보기(`4`) | 입력칸이 없음. 새 문제에는 `a: 정답 보기`와 흐린 `먼저 스스로 답해 보세요` |
| 휴대폰에서 1번(되묻기가 남은 문제) | 되묻기 아래 `a: 정답 보기` · `f: 맞았는데요`와 흐린 `한 번 더: /learn 퀴즈 1 새 답` |
| 휴대폰에서 새 문제의 `a` | 정답과 `o: 맞혔어요` · `x: 틀렸어요` |

## 16. 직접 해 보기 `t` (WT)

준비: 1.7.0에서 쓴 노트가 있습니다. 예: "greet 함수가 이름을 받아 인사하게 해 줘"처럼 코드 몇 줄을 고친 요청. 노트 끝에 `직접 해 보기 · (파일 이름)` 칸이 있고, `이 노트로` 줄에 `t: 직접 해 보기`가 보입니다. 한/영은 **한글** 상태로 시작합니다.

| 누를 것 | 보여야 할 글자 |
| --- | --- |
| 노트 끝 칸을 읽기 | `할 일: …`과 `확인: …` 두 줄만. `고칠 줄`과 `예시 답`은 보이지 않음 |
| 패널에 키가 있고 한글 상태에서 `t` | 아무 일도 없음 (`ㅅ`이 들어가 단축키가 아님) |
| 한/영 키, 그다음 `t` | `이 노트로` 키 줄 → `질문:` 칸 아래에 흐린 `✎ 연습입니다 · 파일은 바뀌지 않습니다`, 줄 번호가 붙은 칸에 원래 줄이 미리 들어 있고 그 위아래 줄이 흐린 번호 줄로 보임. 커서가 칸 안에 있음 |
| 칸 아래 흐린 줄 | `Enter: 확인 · 코드는 영문 상태에서 · Tab: 버튼으로 (1~4 보기)` |
| 고치지 않고 Enter | 노란 `아직 바꾼 곳이 없습니다 · 줄을 고친 뒤 Enter` |
| 한/영을 한글로 바꿔 줄 끝에 몇 글자(예: `ㄱㄷ`)를 치고 Enter | 노란 `코드는 영문 상태에서 적습니다` |
| 칸을 모두 지우고 Enter | 노란 `줄이 비었습니다 · 고친 줄을 적고 Enter · 모르겠으면 '모르겠어요'` |
| 위 세 줄 앞뒤로 `/learn 기록` 맨 아래 | 모델 호출 수가 늘지 않음 |
| 영문 상태로 줄을 할 일과 다르게(틀리게) 고치고 Enter | `확인하는 중입니다…` 뒤 빨간 `✗ 아직입니다 · 한 번 더 고쳐 보세요`(또는 노란 `△ 아직입니다 · 방향은 맞습니다`), 피드백, `되묻기: …`. 커서가 새 칸에 있고 칸에 방금 고친 줄이 들어 있음 |
| 칸 아래 흐린 줄 | `Enter: 다시 확인 · 코드는 영문 상태에서 · Tab: 버튼으로 (a 예시 답)` |
| `Tab` → 영문 상태로 `a` | `✗ 틀림 · 예시 답 봄`(또는 `△ 거의 맞음 · 예시 답 봄`), `예시 답: …`. 커서가 `t: 직접 해 보기`로 |
| 다른 노트에서 `t`, 할 일대로 고치고 Enter | 초록 `✓ 해냈습니다`. 예시 답과 다르게 고쳤으면 그 아래 `예시 답과 견주기: …` |
| 또 다른 노트에서 `t`, 틀리게 고친 뒤 되묻기 칸에서 맞게 고쳐 Enter | 초록 `✓ 해냈습니다 · 되짚어 맞힘` |
| 연습 칸에 몇 글자를 치다가 `Tab` → `2`(전/후) → `1`(노트) → `t` | `Tab`의 다음 자리는 `질문:` 칸이 아니라 버튼이라 `2`가 보기를 바꿈. 돌아오면 연습 칸이 그대로 있고 치던 글이 남아 있음 (원래 줄로 되돌아가지 않음) |
| 확인하는 중(`확인하는 중입니다…`)에 `/reload-plugins` | 다시 불러온 뒤 칸이 다시 보이고, 칸에서 Enter로 다시 확인할 수 있음 |
| 문서만 고친 요청(예: README에 한 줄 더하기)의 노트 | 대개 `직접 해 보기` 칸과 `t`가 없음. 칸이 있으면 `t`를 눌러 고칠 줄이 무엇인지 적어 둠 |
| 1.7.0 전에 쓴 노트 | `직접 확인해 볼 것` 칸 그대로, `t` 없음 |

관찰해 적어 둘 것: 실제 haiku가 `할 일 · 고칠 줄 · 확인 · 예시 답` 네 줄 형식을 지키는지, 고칠 줄을 바뀐 코드에서 찾지 못해(또는 40자를 넘어) `t`가 빠지는 노트가 얼마나 되는지.

## 17. 직접 해 보기: 좁은 패널과 휴대폰 (WT · Remote Control)

| 누를 것 | 보여야 할 글자 |
| --- | --- |
| WT를 120칸으로 줄여 도킹 패널이 좁을 때 `t` | 칸 줄의 번호(`12: …`)와 위아래 흐린 줄의 번호(`11  …` · `13  …`)가 같은 자리에서 시작함. 위아래 긴 줄은 줄바꿈 없이 끝이 잘림 |

| 휴대폰에서 그 `a` | `✗ 틀림 · 예시 답 봄`(또는 `△ 거의 맞음 · 예시 답 봄`)과 예시 답 |

## 18. 오답 노트와 다시 도전 (WT)

준비: 장면 13에서 두 번 다 틀린 문제가 있습니다.

| 누를 것 | 보여야 할 글자 |
| --- | --- |
| 두 번 다 틀린 문제 아래 | 피드백 아래 흐린 한 줄 `헷갈린 점: … · 다음 퀴즈에서 다른 코드로 다시 묻습니다` |
| 좁은 도킹 패널에서 같은 화면 | 그 줄이 잘리지 않고 다음 줄로 이어짐 |
| `3` (개념 모음) | `복습할 개념` 아래 `(개념) · 헷갈린 점: …`. 길면 끝이 `…`이고 패널 폭을 넘지 않음 (WT 한글 폭) |
| `/learn 기록` | 복습 줄에 `(개념) (퀴즈 틀림 오늘)` |
| 다음 날 `/learn 복습` | 그 개념의 문제 제목이 `문제 n/3 · 다시 도전`(뒤에 유형). 답하기 전에는 헷갈린 점이 보이지 않음 |
| 다시 도전 문제를 힌트·되묻기 없이 맞힘 | 초록 `✓ 지난번 헷갈린 점을 바로잡았습니다` |
| (다른 다시 도전 문제를) 또 틀림 | `같은 곳을 또 헷갈렸습니다`. 그 개념을 배운 노트가 패널에 있으면 ` · n: 이 개념을 배운 노트 · 거기서 r로 따라가기`, 다음 답 칸 아래 Tab 안내에 `n 배운 노트` |
| `Tab` → 영문 상태로 `n` | 그 개념을 배운 노트로 감 (답 칸에 `n`이 들어가지 않음) |

관찰해 적어 둘 것: 틀린 답에 `헷갈린 점:` 줄이 대개 붙는지, 문제 글에 지난 헷갈린 점이 그대로 적혀 나오는지.

## 21. 잠깐 오류 · 다시 불러오기 · 사용 한도 (WT)

| 누를 것 | 보여야 할 글자 |
| --- | --- |
| 파일을 고치는 요청, 턴이 끝나 `노트를 쓰는 중입니다…`가 보이자마자 `/reload-plugins` | 노트 칸이 하늘색 `다시 불러온 뒤 이어서 씁니다…`로 바뀐 뒤 노트가 생김 |
| 같은 요청, `노트를 쓰는 중입니다…`가 보이자마자 네트워크를 끊고 10초 안에 다시 연결 | 노트 칸이 노란 `연결이 끊겨 30초 뒤 한 번 더 씁니다… · w로 바로 쓰기`(원인에 따라 `시간이 너무 걸려 …`), 위 버튼 `w: 바로 쓰기`, 30~35초 뒤 노트가 생김 |
| 네트워크를 끊은 채 4분 넘게 둠 | 빨간 `노트를 쓰지 못했습니다: 인터넷 연결을 확인하세요 · 연결되면 w로 다시 쓰기`(원인에 따라 `시간이 너무 걸려 멈췄습니다 · w로 다시 쓰기`) |
| 기다리는 줄이 보이는 동안 `/exit`, 바로 `claude` 다시 켜기 | 대화창에 `learn-notes 점검` 줄이 뜨지 않음. 5분쯤 뒤 그 턴의 노트가 일지 파일에 들어감 |
| 같은 방법으로 노란 `연결이 끊겨 30초 뒤 한 번 더 씁니다… · w로 바로 쓰기`를 다시 띄운 뒤, 네트워크를 다시 연결하고 바로 `/learn 비우기 확인` | 1분이 지나도 노트를 다시 쓰지 않음(`/learn 기록` 맨 아래 호출 수 그대로). 오늘 일지 파일에 그 턴의 바뀐 코드와 `_노트를 쓰지 못했다: 인터넷 연결을 확인하세요 · 연결되면 w로 다시 쓰기_`가 들어감 |
| 다 쓴 노트에서 `w`(다시 쓰기)를 누르고 `노트를 쓰는 중입니다…`가 보이자마자 `/reload-plugins` | 노트 칸이 원래 노트로 돌아오고, 토스트 `다시 불러오는 사이 노트 다시 쓰기가 끊겼습니다 · 원래 노트는 그대로입니다 · w로 다시 쓰기`. 빨간 `중간에 끊겨 멈췄습니다`가 아님 |
| 구독 계정에서 5시간 사용량이 90%를 넘은 상태로 파일을 고치는 요청 | 노트 칸이 노란 `Claude 사용 한도(5시간)를 90% 넘게 써서 자동 노트를 미뤘습니다 · w를 누르면 씁니다`, 토스트 `학습 노트: Claude 사용 한도(5시간)를 90% 넘게 써서 자동 노트를 미뤘습니다 · 패널에서 w를 누르면 씁니다` |
| 같은 날 한 번 더 요청 | 노란 줄은 남고 토스트는 다시 뜨지 않음 |
| API 키로 로그인한 세션에서 같은 요청 | 평소처럼 노트가 생김 |

## 22. 팀 용어 연습 (WT)

준비: 저장소 맨 위 `.claude/learn-notes.md`에 아래처럼 적고, 그 경로의 파일을 만들어 둡니다. 처음 설치한 세션이 아닌 세션에서 이 저장소를 처음 엽니다.

```markdown
## 용어
- **fetcher**: 우리 팀의 API 호출 함수입니다 · `src/lib/fetcher.ts:1-8`
- **캐시 키**: 응답을 캐시에 넣는 이름입니다 · `src\lib\cache.ts:3-9`
- **불변 바인딩**: const로 묶은 이름입니다
```

| 누를 것 | 보여야 할 글자 |
| --- | --- |
| `claude` 시작 | 토스트 `이 저장소의 팀 용어 3개로 연습할 수 있습니다 · /learn 퀴즈` (다른 프로젝트에서 복습할 개념이 3개 이상이거나 풀던 퀴즈가 있으면 끝이 `/learn 퀴즈 팀`). 키를 가져가지 않음 |
| `claude`를 껐다 다시 켜기 | 토스트가 뜨지 않음 (저장소마다 한 번) |
| 노트 없이 `/learn` | 보기 줄과 키 안내, 그 아래 흐린 `팀 용어 3개로 연습할 수 있습니다 · 4에서 s` (복습할 개념이 퀴즈를 채우면 끝이 `/learn 퀴즈 팀`) |
| `3` | `팀 용어 3개 중 0개 만남 · 4에서 s`, 흐린 `아직: fetcher · 캐시 키 외 1개`. 좁은 패널에서는 줄 끝이 잘림 |
| 퀴즈를 한 번도 받지 않은 설치에서 `4` | 흐린 `s를 누르면 이 저장소의 팀 용어로 3문제를 냅니다 · 먼저 떠올려 적어 보세요. 틀린 답을 바로잡을 때 더 오래 남습니다 · 모르면 '모르겠어요'라고 적고 Enter` (복습할 개념도 있으면 `s를 누르면 복습할 개념과 이 저장소의 팀 용어로 n문제를 냅니다`) |
| `4` → `s` | 복습할 때가 된 개념이 없으면 제목 `팀 용어 퀴즈`(있으면 `복습 퀴즈`에 팀 용어가 섞임), `문제 1/3 · 팀 용어 · …`, 그 아래 흐린 `팀 코드 (fetcher.ts 1~8줄)` |
| 캐시 키 문제 | 흐린 `팀 코드 (cache.ts 3~9줄)` (역슬래시 경로도 읽음) |
| 불변 바인딩 문제 | `팀 코드` 줄 없이 설명만으로 물음 |
| 답을 적고 Enter (되묻기가 나오면 한 번 더 뒤에) | 피드백 아래 흐린 `팀 용어를 개념 모음에 넣었습니다` (완전히 틀렸으면 ` · 다음 퀴즈 맨 앞에 나옵니다`) |
| `3` | 그 개념 줄의 만난 횟수 바로 뒤에 흐린 `· 팀 용어` (`fetcher ×1 · 팀 용어 · 다음 복습 …`). WT 120칸의 도킹 패널에서도 `팀 용어`까지 보임. 머리말 아래 `팀 용어 3개 중 1개 만남 · 4에서 s` |
| 대화 입력칸에 `/learn 퀴즈 팀` | `팀 용어 퀴즈 · n문제`, 문제 앞에 `(팀 용어 · 팀 코드 cache.ts 3~9줄)` 같은 표시 (아직 안 만난 용어가 먼저) |
| `/learn 기록` | `- 이 저장소 팀 용어: 3개 중 1개 만남 · 아직 2개 (/learn 퀴즈 팀)` |
| `## 용어`를 지운 저장소에서 `/learn 퀴즈 팀` | `이 저장소에는 팀 용어가 없습니다 · .claude/learn-notes.md의 ## 용어에 적습니다` |
| 저장소 밖을 가리키는 링크(`mklink` · `ln -s`)를 용어 경로로 적고 `/learn 퀴즈 팀` | 그 용어 문제에 `팀 코드` 줄이 없음 |
| 용어 경로를 `wp-config.php:1-5`나 `appsettings.Development.json:1-5`로 적고 `/learn 퀴즈 팀` | 그 용어 문제에 `팀 코드` 줄이 없고 설명만으로 물음. 문제와 대화창 어디에도 그 파일의 비밀번호가 없음 |

관찰해 적어 둘 것: 실제 haiku가 팀 코드로 예측·바꿔 보기 문제를 내는지, 팀 코드가 없는 용어를 설명만으로 '왜'로 묻는지, 개념 이름을 문제에 그대로 쓰는지.

## 23. 직접 해 보기 칸의 초점 (WT)

준비: 장면 16처럼 1.7.0 노트가 있고, 패널은 전체 화면 오른쪽에 있으며, 한/영은 **한글** 상태로 시작합니다.

| 누를 것 | 보여야 할 글자 |
| --- | --- |
| `ctrl+x tab` → 한/영 키 → `t` → `Esc` | 대화 입력칸으로 돌아감. 연습 칸 아래 흐린 줄이 `Enter: 확인 · 코드는 영문 상태에서 · ctrl+x tab: 고칠 줄 칸으로` |
| `ctrl+x tab` | 커서가 연습 칸 안에 있음. 칸 아래 줄이 `… · Tab: 버튼으로 (1~4 보기)`로 바뀜 |
| 영문 상태로 `return wrap(n + 1)`처럼 `r` · `e` · `w` · `a` · `n` · `p`가 든 코드를 침 | 글자가 모두 칸에 들어감. 노트를 다시 쓰거나(`w`) 더 쉽게(`e`) · 예시로 따라가기(`r`)가 시작되거나 다른 노트로(`n` · `p`) 가지 않음 |
| 틀리게 고쳐 Enter, 되묻기가 나오면 `/reload-plugins` 뒤 `ctrl+x tab` | 다시 그려진 패널에서 커서가 한 번 더 칸(내 줄이 들어 있음)에 있음 |
| 이어서 `Tab` | 초점이 `a: 예시 답`으로 감 (`질문:` 칸으로 가지 않음) |
| 되묻기를 받은 채 `claude`를 껐다 같은 날 다시 켜고 `/learn` → `ctrl+x tab` | 커서가 그 노트의 한 번 더 칸에 있음 (노트가 지금 보는 노트일 때) |

## 24. 창 둘에서 같은 퀴즈 (WT, 창 둘)

준비: 같은 프로젝트 폴더에서 터미널 두 개(창 A · 창 B)에 1.7.0 `claude`를 켭니다. 복습할 개념이 있어야 합니다.

| 누를 것 | 보여야 할 글자 |
| --- | --- |
| 창 A에서 `/learn 복습`으로 퀴즈를 받고, 창 B에서 `/learn` → `4` | 두 창에 같은 문제가 보임 |
| 창 A에서 1번에 일부러 틀린 답을 적고 Enter | 창 A에 `되묻기:`와 빈 `내 답 (한 번 더)` 칸 |
| 창 B에서 패널의 `h`(1번 힌트)를 누르거나, 대화 입력칸에 `/learn 퀴즈 2 (답)`으로 2번에 답함 | 힌트가 보이거나 2번이 채점됨 |
| 창 A로 돌아와 `/learn 퀴즈` | 1번 아래 내 첫 답과 `되묻기: …`가 그대로 남아 있음 (창 B의 동작으로 사라지지 않음) |
| 창 A에서 `s`를 두 번 눌러 새 퀴즈를 받음 | 새 퀴즈가 나오고, 1번이 첫 판정대로 매겨짐: `/learn 기록`의 복습할 개념에 그 개념이 `(퀴즈 틀림 오늘)`로 보임 (첫 판정이 거의였으면 날짜 없이 한 단계 내려감) |
| (새 퀴즈로 다시) 창 A가 1번에 첫 답을 해 되묻기를 받은 뒤, 1번을 아직 첫 문제로 보여 주는 창 B의 `내 답` 칸에 답을 적고 Enter | 채점 뒤 창 B에 빨간 `이 문제는 그사이 다른 창에서 먼저 답했습니다. 한 번 더 적어 보세요.`, 1번 자리에 창 A의 되묻기와 `내 답 (한 번 더)` 칸 |
| 창 A에서 한 번 더를 채점한 뒤, 같은 문제를 아직 한 번 더 칸으로 보여 주는 창 B에서 Enter | 창 B에 `이 문제는 다른 창에서 이미 채점했습니다.`, `/learn 기록` 맨 아래 호출 수가 늘지 않음 |

관찰해 적어 둘 것: 두 창이 잠깐 서로 다른 문제를 보여 줄 때 무엇을 눌렀는지, 그때 패널에 뜬 빨간 줄.
